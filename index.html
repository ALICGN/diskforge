Fylr

pacman-Repository für Fylr – Disk-Analyzer, Duplikatfinder und Dateisortierer.

Einrichten

[fylr]
SigLevel = Optional TrustAll
Server = https://alicgn.github.io/fylr/x86_64

Danach:

sudo pacman -Sy
sudo -S -p '' pacman -S fylr-bin

Das Repository ist nicht signiert; SigLevel = Optional TrustAll akzeptiert es. Alternativ direkt die Pakete aus den Releases installieren.
