# Verhaltenskodex

## Unser Versprechen

Wir wollen eine Umgebung, in der sich alle Beteiligten wohlfühlen — unabhängig von
Erfahrung, Herkunft, Religion, Geschlecht, sexueller Orientierung oder Behinderung.

## Erwartetes Verhalten

- Respektvoll und sachlich diskutieren, Kritik an Code statt an Personen.
- Geduld mit Einsteiger:innen; „das ist trivial" ist keine hilfreiche Antwort.
- Fehler eingestehen und korrigieren.
- Auf die Ziele des Projekts fokussiert bleiben.

## Nicht akzeptabel

- Beleidigungen, persönliche Angriffe, Diskriminierung, sexuelle Anspielungen.
- Belästigung jeder Art, auch per DM.
- Veröffentlichen privater Informationen anderer ohne Zustimmung.
- Dauerhaftes Stören von Diskussionen.

## Durchsetzung

Verstöße meldest du vertraulich an den Maintainer (Ali Utlu, Kontakt siehe
GitHub-Profil). Mögliche Konsequenzen: Verwarnung, Löschen von Kommentaren,
temporärer oder dauerhafter Ausschluss aus dem Projekt.

Dieser Kodex gilt in Issues, Pull Requests, Discussions und allen Räumen, in denen
das Projekt vertreten wird.
